# 實際上班人力：小數點後三位修改對照

> 後續已新增四個單位的住院分類。若要重新套用程式，請一併參閱 [住院分類欄位修改對照](住院分類欄位_修改對照.md)，以保留最新分類功能。

修改日期：2026-10-26

適用檔案：`index.html`。以下提供完整對應段落，可將「修改前」整段替換為「修改後」。本機程式已套用全部修改。

人力由護理部依其標準人工填入；一般病房與特殊單位均接受非負數、最多小數點後三位。暫存和送出保留輸入的小數，不再截成整數；超過可接受精度時，儲存前由輸入欄位檢查並提示修正。

人力明細與加總以最多三位小數顯示，省略尾端的 0（例如 6.500 顯示為 6.5），避免浮點加總出現多餘尾數。CSV 保留人力小數；護病比延用原公式並使用含小數的人力計算。

程式驗證已涵蓋一般單位及特殊單位的暫存、送出與 JSON 保存、小數人力與整數事件欄位、班別與全日加總、無效人力輸入阻擋儲存，以及 CSV 匯出。使用隔離的模擬資料執行驗證。
