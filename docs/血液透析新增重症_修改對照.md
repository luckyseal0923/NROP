# 血液透析新增重症欄位：修改前後對照

修改日期：2026-10-26。適用檔案：`index.html`。本機已套用以下修改。

洗腎室的血液透析現在包含「門診」、「住院」、「重症」三個獨立輸入欄位。新增欄位名稱為 `hemodialysisCritical`，沿用特殊單位的儲存流程，依日期及班別分別暫存或正式送出。「特殊單位每日營運統整」同步顯示三班合計的重症數值，與門診、住院及腹膜透析分開。

舊紀錄沒有重症欄位時，沿用現有欄位機制先顯示 0，可由填報者補登；新的示範紀錄也會初始化為 0。三分類由人工填入，程式不會將既有住院數自動分配至重症。

已使用隔離資料與模擬 DOM 執行程式驗證：三欄顯示、舊紀錄載入、暫存、正式送出、重新載入、零值保存、三班分類加總，並確認原有人力三位小數及腹膜透析欄位可保留。

以下為完整對應段落，可將「修改前」整段替換為「修改後」。

## 每日營運統整（完整特殊單位表格處理段落）

修改前：

```javascript
      $('#specialOpsTable').innerHTML=operationalUnits.map(u=>{
        const records=shifts.map(s=>data[operationalKey(date,s,u.id)]||{status:'empty'}),sum=f=>records.reduce((n,r)=>n+(r[f]||0),0),last=records[2];
        let summary='';
        if(u.type==='emergency')summary=`來診 ${sum('visits')}、住院 ${sum('admitted')}、E班留觀 ${last.observation||0}`;

        if(u.type==='nursingHome')summary=`住民 ${last.residents||0}、保留床 ${last.reserved||0}、空床 ${Math.max(u.beds-(last.residents||0)-(last.reserved||0),0)}`;
        if(u.type==='dialysis')summary=`血液透析門診 ${sum('hemodialysisOutpatient')}、住院 ${sum('hemodialysisInpatient')}、腹膜透析 ${sum('peritonealDialysis')}`;
        const state=r=>`<span class="status ${r.status||'empty'}">${r.status==='submitted'?'完成':r.status==='draft'?'暫存':'未填'}</span>`;
        return `<tr><td><b>${u.id}</b></td><td>${summary}</td><td>${state(records[0])}</td><td>${state(records[1])}</td><td>${state(records[2])}</td></tr>`;
      }).join('');
```
