# 護理之家護理師／護佐人力：修改前後對照

修改日期：2026-10-26。適用檔案：`index.html`。本機已套用以下修改。

護理之家分別填寫「護理師」與「護佐」，兩欄均接受非負數、最多小數點後三位。「上班人力（自動合計）」為唯讀，依兩欄加總即時更新；暫存或送出時重新計算合計後保存。兩職類數值仍由人工填入。

例如：護理師 1.234 ＋ 護佐 2.345 ＝ 上班人力 3.579。加總以千分之一為單位計算，避免顯示多餘浮點尾數；顯示沿用最多三位小數並省略尾端的 0。

舊紀錄若只有非零人力總數，保留原總數並提示補填分類。護理師與護佐兩欄先留空，填齊後才能暫存或送出；無此職類請填 0。原總數為 0 或全新紀錄時，兩欄可預設為 0。新建立的示範紀錄也保留既有總數，等待人工補填分類。

每日全院人力使用護理師加護佐的合計，每筆只計入一次；護理之家每日營運統整另列三班護理師、護佐與合計人次。若當日仍有舊紀錄待分類，先顯示原有合計與待補分類提示。

隔離的模擬 DOM 與資料程式驗證已通過：三位小數欄位、即時加總、0.1＋0.2 與千分位、合計唯讀且儲存時重算、暫存／送出／重載、零值、負數／超過三位小數／空白分類阻擋儲存、舊紀錄保護、每日職類及總人力加總，以及其他特殊單位與血液透析重症欄位保留。未操作實際瀏覽器資料。
