# 背景與區塊對比加強：修改前後對照

修改日期：2026-10-26。修改檔案：`assets/theme.css`。本機已套用以下樣式。

頁面底色由接近白色的淡粉改為較深的藕粉，內容卡片維持白色；頁首改為莓果色搭配白字；卡片標題列、表格表頭與填報資訊區使用不同深度的玫瑰色。同步加深分隔線、輸入框邊界與陰影，選取中的頁籤改為深色底白字。首頁插圖以獨立淺色圖框呈現，窄螢幕維持上下排列。

## 配色調整

| 項目 | 修改前 | 修改後 |
|---|---|---|
| 頁面背景 | `#fff7fa` | `#e8cad8` |
| 頁首背景 | `#fffafb` | `#7e3658` |
| 內容卡片 | 白色 | 白色 |
| 區塊分隔線 | `#ecd9e1` | `#c591aa` |
| 輸入框邊線 | `#b9879e` | `#99647d` |
| 卡片標題列 | 白色 | `#f1ccdd` |
| 表格表頭 | `#fff3f7` | `#eac0d3` |

## 檢查

已檢查 CSS 區塊結構、首頁圖片路徑及 15 組主要文字／背景色對比，這些組合皆達 4.5:1 以上；輸入框邊線與白底的對比超過 3:1。這是顏色計算結果，實際瀏覽器視覺效果仍可由本機頁面重新整理確認。

白色卡片與頁面底色的顏色對比由 1.05:1 提升至 1.51:1，並搭配較深邊框與陰影區分區塊。這個數值僅用於比較背景層次。
