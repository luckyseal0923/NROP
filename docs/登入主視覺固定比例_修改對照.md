# 登入主視覺固定比例：完整修改前後對照

原因：原圖使用 object-fit: cover 填滿整個左欄，右側表單增高時，圖片框隨之增高並重新裁切。修改後使用獨立 3:4 比例容器，完整呈現原圖；在相同視窗寬度下，登入／申請切換不改變圖片高度。文字與漸層跟隨固定比例容器，較高的表單下方以深藍背景延伸。

手機依可用寬度維持 3:4，卡片上下排列。以下為完整檔案，可直接複製替換。
