# 密碼重設信主旨與內容修改對照

日期：2026-10-27。依使用者確認文案套用，網站範本發布名稱 NROP-20261027-05。

## Auth 設定

只調整 supabase-test 的 recovery 兩個來源變數；Compose 已有對應，不修改整份 Compose。

修改前，兩個欄位皆空白，使用內建英文範本：

```dotenv
MAILER_SUBJECTS_RECOVERY=
MAILER_TEMPLATES_RECOVERY=
```

修改後：

```dotenv
MAILER_SUBJECTS_RECOVERY=【NROP 護理即時動態平台】重設密碼通知
MAILER_TEMPLATES_RECOVERY=https://nrop.wfhai.org/auth-emails/recovery.html
```

先發布並確認範本網址可讀取，再更新這兩個欄位，重新啟動目前版本。寄件地址與 SMTP 憑證不變；其他信件類型不變。回復時將兩欄改回原空白，再重新啟動。

## Dockerfile

### 修改前（完整檔案）

```dockerfile
FROM node:22-alpine AS build
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci
# 這兩個值是公開設定，可做 build arguments；不是資料庫密碼或 service_role。
ARG NEXT_PUBLIC_SUPABASE_URL
ARG NEXT_PUBLIC_SUPABASE_ANON_KEY
ENV NEXT_PUBLIC_SUPABASE_URL=$NEXT_PUBLIC_SUPABASE_URL
ENV NEXT_PUBLIC_SUPABASE_ANON_KEY=$NEXT_PUBLIC_SUPABASE_ANON_KEY
COPY index.html vite.config.js ./
COPY src ./src
COPY assets ./assets
RUN npm run build

FROM nginx:alpine
COPY nginx.conf /etc/nginx/conf.d/default.conf
COPY --from=build /app/dist /usr/share/nginx/html
EXPOSE 80
```

實際套用結果另記錄；沒有代寄測試信或更改使用者密碼，下一封實際信件仍由使用者驗收。
