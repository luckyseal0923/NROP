# 護理部申請、六碼英數密碼與管理者審核：完整修改對照

日期：2026-10-26。依使用者決定：申請單位新增護理部，密碼至少六碼且含英文／數字，取消註冊驗證信，改由系統管理者核准。

## 套用到既有 Supabase

1. 在 SQL Editor 執行完整 [UPGRADE_005_006.sql](../supabase/UPGRADE_005_006.sql)。此更新可重跑，保留全部既有成員與 DEMO。
2. Coolify 的 supabase-test → Environment Variables：ENABLE_EMAIL_AUTOCONFIRM 設為 true，儲存並 Restart current version。此為共用 Auth 設定，SQL 無法更動，使用者明確同意後已套用並重啟，公開 Auth API 已確認 mailer_autoconfirm=true；005／006 SQL 仍待使用者執行。
3. 重新整理 NROP，申請後會停在待審核，必須由系統管理者指定角色／單位並啟用。

護理部是申請單位；不增加填報或病床數。29 個申請單位、28 個填報單位。六碼純英文或純數字皆不通過前端規則；Auth 服務端密碼規則另見安裝指南。
